Binary Image classification tasks on the ISIC 2016 and SARS-COV-2 datasets one imbalanced and one balanced respectively to test the extent of two base classifiers against the basic CNN Models and ViT.


The base classifiers have two kinds of learners, namely lazy learners, which store the training data. It waits until it has been given test data to evaluate. For this case, the K-NN which is a lazy learner, has been used . The Eager learner builds a classification model before a test data has been given. It classifies the test data based on the classification model. For this case, the Naive Bayes classifier has been used . Now, to test the extent of these classifiers, I use them to compare with some basic CNN models like AlexNet , DenseNet201 , ResNet101 , MobileNet-V2 , and a transformer-based model, ViT .
There are many classification datasets available, but ISIC 2016 dataset is one of the globally available public datasets from ISIC and an imbalanced one. And with respect to CT images, a recent virus that shook the world, I took the SARS-CoV-2 dataset for the purpose of my project which is also a balanced dataset.
